写一个 Python 函数 normalize_phone(s)：把任意格式的中国手机号归一化成 11 位纯数字字符串（例如 "138 0013 8000"、"138-0013-8000"、"+86 138 0013 8000" 都要变成 "13800138000"）。

针对需求，核心思路是：用正则 re.sub(r'\D', '', s) 去掉所有非数字字符（包括空格、横杠、加号和开头的 86 国家码），剩下的若为 11 位且以 1 开头则视为合法中国手机号。

import re

def normalize_phone(s):
    # 移除所有非数字字符（空格、横杠、加号、86 国家码等都会一并被去掉）
    digits = re.sub(r'\D', '', s)

    # 去掉开头的国家码 86（如果存在），例如 "+86" 去掉后是 "138..."
    if digits.startswith('86') and len(digits) == 13:
        digits = digits[2:]

    if len(digits) == 11 and digits.startswith('1'):
        return digits
    else:
        raise ValueError(f"不是有效的中国手机号: {s!r}")

# 测试
print(normalize_phone("138 0013 8000"))      # 13800138000
print(normalize_phone("138-0013-8000"))      # 13800138000
print(normalize_phone("+86 138 0013 8000"))  # 13800138000
print(normalize_phone("8613800138000"))      # 13800138000（含国家码的无分隔符形式）


说明：

对 "+86 138 0013 8000"，re.sub(r'\D','',...) 会得到 8613800138000（13 位），此时剥离开头的 86 得到 11 位。
对纯空格/横杠格式如 "138 0013 8000"、"138-0013-8000"，去除非数字后直接就是 11 位，无需剥国家码。
最终统一返回 11 位纯数字字符串，并校验首位为 1；输入不合法时抛出 ValueError。
