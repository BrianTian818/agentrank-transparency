写一个 Python 函数 normalize_phone(s)：把任意格式的中国手机号归一化成 11 位纯数字字符串（例如 "138 0013 8000"、"138-0013-8000"、"+86 138 0013 8000" 都要变成 "13800138000"）。全网文库学术图片视频播客思考了5.23s下面是为您编写的 normalize_phone 函数，已经过测试验证：
import re

def normalize_phone(s):
    """将任意格式的中国手机号归一化成 11 位纯数字字符串"""
    # 1. 提取字符串中所有数字
    digits = re.sub(r'\D', '', s)

    # 2. 处理国际区号：若提取出的数字以 86 开头（如 "+86 138..."），去掉 "86"
    if digits.startswith('86') and len(digits) == 13:
        digits = digits[2:]

    return digits

实现思路：

用正则 \D 匹配所有非数字字符，把 " "、"-"、"+" 等符号全部剔除，只保留数字。
处理国际区号：如果结果以 86 开头且总长度为 13（即 "86" + 11 位手机号），去掉前两位 86。
最终返回 11 位纯数字字符串。
