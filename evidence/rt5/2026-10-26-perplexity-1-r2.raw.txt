可以先去掉空格、短横线、括号等分隔符，再处理可选的 86 或 0086 前缀，最后检查是否为 11 位手机号。不符合规则的输入抛出 ValueError。

python
import re
import unicodedata


def normalize_phone(s: str) -> str:
    """归一化中国大陆手机号；格式不合法时抛出 ValueError。"""
    if not isinstance(s, str):
        raise TypeError("手机号必须是字符串")

    # 兼容全角数字、全角加号等字符。
    text = unicodedata.normalize("NFKC", s).strip()

    # 仅允许数字、开头的可选加号，以及常见分隔符。
    # 不直接删除所有非数字字符，避免把含字母的错误输入变成合法号码。
    text = re.sub(r"[\s()（）\-‐‑‒–—―.]+", "", text)

    if not re.fullmatch(r"\+?[0-9]+", text):
        raise ValueError("手机号包含不支持的字符")

    if text.startswith("+86"):
        number = text[3:]
    elif text.startswith("0086"):
        number = text[4:]
    elif text.startswith("86") and len(text) == 13:
        number = text[2:]
    else:
        number = text

    if not re.fullmatch(r"1[3-9][0-9]{9}", number):
        raise ValueError("手机号格式不合法")

    return number
使用示例
python
assert normalize_phone("138 0013 8000") == "13800138000"
assert normalize_phone("138-0013-8000") == "13800138000"
assert normalize_phone("+86 138 0013 8000") == "13800138000"
assert normalize_phone("0086 (138) 0013-8000") == "13800138000"
assert normalize_phone("8613800138000") == "13800138000"
assert normalize_phone("１３８ ００１３ ８０００") == "13800138000"

# 以下输入会抛出 ValueError：
# normalize_phone("abc13800138000")
# normalize_phone("13800138000 转 123")
# normalize_phone("138001380")

注意：这里把有效格式定义为 1[3-9] 开头、总共 11 位数字；只检查格式，不验证号码是否真实存在或已经开通。
